Fixed decision rule

The 95% interval-score comparison

Simulation minus Mack; a lower score is better. The full paired 95% bootstrap interval must be below zero to select simulation. Changing the coverage display does not change that rule.

1,000 paired entity bootstraps. Corporate links and common calendar shocks can weaken the independence assumption. Finite simulation quantiles also carry Monte Carlo noise.
